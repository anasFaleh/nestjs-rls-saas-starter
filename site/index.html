What's inside

  
Four layers of isolation, and the tests to prove each one

  

    
🛡️
RLS done right
ENABLE + FORCE, policies with USING and WITH CHECK, tenant set per transaction so pooled connections never leak.

    
🔒
A role that can't cheat
The API runs as a non-owner role without BYPASSRLS, and refuses to boot if pointed at one that could.

    
🔑
Secure tenant resolution
API key → tenant through a narrow SECURITY DEFINER function. Clients never choose their tenant.

    
✅
Tests that prove it
Cross-tenant read, update, delete and insert, raw SQL, concurrency, plus a privilege audit that fails CI when a table ships without RLS.

    
☁️
Works on managed Postgres
Tested with a non-superuser owner, the way Neon, Supabase and RDS give it to you.

    
🤖
AI-agent friendly
AGENTS.md teaches Claude Code, Cursor and Copilot the tenant rules, so generated code stays safe.
